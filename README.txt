mn61 Client - Forge 1.8.9
Requirements: JDK 8, Gradle wrapper for ForgeGradle 2.1 (Gradle 2.14).
Setup:   gradle setupDecompWorkspace && gradle eclipse (or idea)
Run:     gradle runClient
Build:   gradle build   -> build/libs/mn61-client-1.0.jar (put in .minecraft/mods with Forge 1.8.9 installed)
Menu key: Right Shift (changeable in Controls)
